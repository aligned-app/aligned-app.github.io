The core idea

The whole carousel is one continuous canvas

Other tools model a carousel as N separate square artboards. ALIGNED models it as one long canvas — a single image can run across three or four slides, and the seam becomes part of the composition. It slices on export, so nudging an element never means re-slicing by hand.

  • Snapping and guides that cross page boundaries — one set of guides shared by the entire project.
  • Text snaps on the outer edge of the glyphs, not the bounding box — when text looks aligned, it is.
  • Three-level magnetic snapping, group align, equal distribution — every element lands exactly where it should.

Features

From layout to motion, in one place

Every clip below is a real screen recording, not a mockup.

Vertical & CJK typography

One-tap vertical (top-to-bottom) text with proper punctuation forms; letter spacing, line height and paragraph spacing share one consistent language, with true optical centering.

Multi-select & cross-project copy

Copy multiple objects keeping their relative positions — even into another project. Your layout assets travel with you.

Grid layouts

Lay down 2-up, 3-up, 2×2 or 3×3 grids in one tap, then fill each cell with a photo or video.

Entrance animations

Four effects each for text and objects, two-stage zoom, one-tap staggered reveal. Animated pages export as mp4 — what you see is what you get.

Multi-image loops

Several images cycling inside one frame, with hard-cut or continuous-mask transitions.

3D objects

Drop in a .glb model: still, slow spin, or fast spin with a brake — you even choose which face it stops on.

One more thing

AI can write project files directly

The .alignproj project file is documented JSON, with a spec written for LLMs to read. Have Claude or GPT draft a whole carousel, open the file in ALIGNED — and every block is still live and editable, not a flattened image.

Read the spec (GitHub)

  "pages": 4,
  "ratio": "4:5",
  "objects": [
    { "type": "image",
      "spansPages": [1, 2, 3] },
    { "type": "text",
      "content": "Across the seam",
      "vertical": true }

FAQ

Things you might be wondering

Is ALIGNED free?

Every feature is free for now. The Mac and Windows versions are open source under GPL-3.0; the name and logo are trademarks and not covered by it — if you fork, please rename.

Where does my work live?

Only on your device. ALIGNED works fully offline — no account, no cloud, no telemetry. It opens files from your disk and writes them back.

Does it run on Intel Macs?

No. The Mac version requires Apple Silicon (M1 or newer) and macOS 13 or later.

Windows shows a warning on install?

The Windows installer isn't code-signed yet, so SmartScreen shows a prompt — click "More info → Run anyway". The installer matches the source published on GitHub.

How is this different from Canva?

ALIGNED isn't a template tool — no marketplace, no cloud, no account. It solves one specific problem: laying out, aligning and slicing images that span multiple slides — the thing every other tool makes you do with manual slicing, over and over.

How do I report a problem?

Email alignediosapp@gmail.com or open an issue on GitHub — we read and answer personally. It's a personal project maintained around client work, so support is best-effort, and we'd rather say that up front.
