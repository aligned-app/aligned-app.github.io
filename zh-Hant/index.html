ALIGNED 是為 Instagram 多頁輪播打造的排版工具。照片、文字、影片，像雜誌內頁一樣跨頁編排、精準對齊、即時預覽，一次匯出整組貼文。

左右滑動——六支功能亮點

招牌功能

整個輪播，
是一條連續畫布

別的工具把輪播當成 N 張獨立的方形畫板；ALIGNED 把它當成一條長畫布——一張圖可以橫跨三、四頁，頁縫變成構圖的一部分。匯出時自動切片，動一個物件也不用重切。

  • 跨頁吸附與參考線——磁吸和對齊基準不受頁面邊界限制，整份專案共用同一組參考線。
  • 文字以字身外緣吸附——不是吸附含空白的外框，字看起來對齊就是真的對齊。
  • 三段磁吸、群組對齊、等距分布——每個元素都落在該在的位置。

功能

從排版到動態，一站做完

以下每支影片都是實際操作錄影，不是概念示意。

直排與中文排版

直排一鍵切換，標點自動轉直排字形；字距、行距、段落間距同一套語言，加大字距後置中仍是真正的光學置中。

多選與跨專案複製

多選物件保持相對位置複製，也能整組複製到另一個專案——版面資產帶著走。

欄位版面

一鍵鋪出兩格、三格、2×2、3×3 的格狀版面，每一格再填入照片或影片。

出場動畫

文字與物件各四種效果、兩段式縮放、一鍵「陸續出現」。會動的頁匯出時自動合成 mp4，所見即所得。

多圖輪播

同一個框放多張圖循環播放，直切或連續遮罩兩種轉場。

3D 物件

拖入 .glb 模型：靜止、慢慢轉圈、或快轉煞停——連停在哪一面都能指定。

獨家

AI 也能直接寫專案檔

ALIGNED 的專案檔 .alignproj 是有完整文件的 JSON。任何 AI 讀完規格書，就能替你產出一整份輪播——在 ALIGNED 打開，每個物件都還是活的、可編輯的，不是壓平的圖片。

常見問題

先回答你可能想問的

ALIGNED 是免費的嗎？

Mac 與 Windows 版所有功能免費、以 GPL-3.0 開源；iPhone／iPad 版免費下載，進階功能採 Pro 訂閱（7 天免費試用）。名稱與 logo 是商標、不在授權範圍內，fork 請改名。

我的作品存在哪裡？

只存在你的裝置上。ALIGNED 完全離線運作——沒有帳號、沒有雲端、沒有遙測，它從你的磁碟開檔、寫回你的磁碟。

Intel Mac 可以用嗎？

不行。Mac 版需要 Apple Silicon（M1 或更新）與 macOS 13 以上。

Windows 安裝時跳出警告？

Windows 安裝檔尚未購買簽章憑證，SmartScreen 會出現提示——點「其他資訊 → 仍要執行」即可。安裝檔內容與 GitHub 上的原始碼一致。

跟 Canva 這類工具差在哪？

ALIGNED 不是範本工具，沒有素材市集、雲端與帳號。它解的是一件事：「一張圖橫跨多頁」的排版、對齊與切片——這件事在別的工具裡都得手動切圖，動一下就重切一次。
